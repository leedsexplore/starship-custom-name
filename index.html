Engraved export uses a true boolean cut. Live preview stays inset for speed.

The parametric CAD loads at true 1:200 — 100% is already H 260.5 × Ø45 mm on a Prusa CORE One (250×220×270). The classic mesh needs ~215%. Engines stay recessed inside the skirt. Empty name on Original CAD at 1:200 downloads the exact Printables hex STL / MMU; at 1:300 downloads the A1-mini one-piece. 1:250 and other scales are customizer-scaled from the same mesh. With a name, 3MF is Hull + Letters. MMU 3MF is 1:200 only.

Named export uses the smooth CAD mesh so lettering/CSG stays reliable. Hex tile plates are in the empty-name Printables files (or GitHub Releases).

OpenSCAD params are for the classic remix flat path (no hull wrap). Prefer the web export for Original CAD.
